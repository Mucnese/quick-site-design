Bibliotheken
============

Diese drei Dateien muessen hier liegen, sonst startet die Anwendung nicht.
Dazu kommt web-ifc fuer den IFC-Import (siehe unten); es wird erst beim ersten
IFC-Import nachgeladen und ist fuer den Start nicht noetig.
Sie liegen bewusst lokal bei und werden nicht von einem CDN geladen: so
gehen beim Aufruf der Seite keine Besucherdaten an fremde Server.

Herunterzuladen
---------------

1. three.min.js
   https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
   -> hier als  three.min.js  speichern

2. OrbitControls.js
   https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/controls/OrbitControls.js
   -> hier als  OrbitControls.js  speichern

3. geotiff.js
   https://cdn.jsdelivr.net/npm/geotiff@2.1.3/dist-browser/geotiff.js
   -> hier als  geotiff.js  speichern

4. web-ifc (nur fuer den IFC-Import), Version 0.0.79
   npm-Paket web-ifc: https://registry.npmjs.org/web-ifc/-/web-ifc-0.0.79.tgz
   aus dem Paket (Ordner package/) zwei Dateien hier ablegen:
     web-ifc-api-iife.js  -> hier als  web-ifc-api-iife.js
     web-ifc.wasm         -> hier als  web-ifc.wasm
   (die Dateien sind unveraendert; SHA-256 der Fassung im Repository:
    web-ifc-api-iife.js  e472e5d856342ff5be74a9f0906ba7df9cd10a0f1c809715f8315af3c3dbf5c2
    web-ifc.wasm         5f28f448c35c47b87010a51a8812b4301a58330b6affdb1485f23f6aef6f9e07)
   Quelltext: https://github.com/ThatOpen/engine_web-ifc

Wichtig: Die Versionen nicht wechseln. Die Anwendung ist gegen three.js r128
gebaut; neuere Fassungen haben eine andere Schnittstelle.

Im Browser: Link oeffnen, dann Ablage -> Sichern unter. Oder im Terminal:

  curl -o three.min.js     https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
  curl -o OrbitControls.js https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/controls/OrbitControls.js
  curl -o geotiff.js       https://cdn.jsdelivr.net/npm/geotiff@2.1.3/dist-browser/geotiff.js
